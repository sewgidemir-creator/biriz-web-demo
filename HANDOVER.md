# HANDOVER — Bir İZ Derneği web demo (birizdernegi.org rebuild)

Audience: the next developer or AI assistant (e.g. Claude) continuing this project.
Language of the site: **Turkish only** (`<html lang="tr">`). No English pages.

## 1. What this is
A static, dependency-free HTML/CSS/JS demo of the approved information architecture (IA) from the
İletişim Komitesi. Built 2026-10-05. Pages are generated by a tiny Python script (`_kaynak/build.py`)
from shared templates (`common.py`) and a content file (`data.py`); the generated `.html` files are committed
and are the deliverable. **Edit `_kaynak/*` and re-run the build** instead of hand-editing generated HTML,
or hand-edit HTML and stop using the build (pick one; the build overwrites all 11 pages).

|---|------|-----------|-------|
| 1 | index.html | Ana Sayfa | hero, intro, stats (`data-count`), 3 project cards, 6 work-area chips, partner logo strip (placeholders), 3 latest news, triple CTA |
| 2 | hakkimizda.html | Hakkımızda | about text (kept from live site), Misyon A/B + Vizyon A/B drafts, 7 values, timeline |

| 6 | projeler.html | Projeler | 23 cards, JS filter by `data-tema` + `data-durum`; deep-link `?tema=goc&durum=tamam` |
| 7 | isbirlikleri.html | İş Birlikleri | grouped: Kamu / Uluslararası / Akademik / Özel Sektör / STK (31 names) |
| 8 | haberler.html | Haberler | 12 items grouped by year, newest first |
| 9 | kaynaklar.html | Kaynaklar | corporate docs, project materials, `#bagisci-haklari`, `#rehber` teaser, `#kvkk` placeholder |
| 10 | iletisim.html | İletişim | front-end-only form (preventDefault → success message), `?konu=` preselect, `#gonullu` anchor |
| 11 | bagis.html | Bağış Yap (header CTA) | impact narrative, bireysel/kurumsal/gönüllü, 3 IBAN placeholders with copy buttons, donor-rights link |

Nav implementation: on desktop, Hakkımızda / Yönetim Kurulu / Ekibimiz are grouped under a **“Hakkımızda ▾”**
dropdown to fit 11 items + CTA in one row (order preserved). Below 1180px the menu becomes a flat
hamburger list containing all items. Active state: `aria-current="page"` on the link (teal bg + yellow underline);
the dropdown button gets `.is-active` when a child page is active. Header CTA “Bağış Yap” → bagis.html on every page.
The footer is identical on every page (shared, not CSS `position: fixed` — a viewport-fixed footer would hide content on mobile).

## 3. Design tokens (css/styles.css `:root`)
- Teal `#46bfb9` (brand) · teal-700 `#17807b` (text/buttons on white, AA contrast) · teal-50 `#eaf8f7`
- Yellow `#fdbf0e` (CTA “Bağış Yap”, accents; always with dark text `#1b2a33`)
- Blue `#1e73be` (secondary/partner CTA, links)
- Ink `#1b2a33`, body text `#3c4d57`, muted `#5f707a`, lines `#e3e9ec`
- Fonts: Plus Jakarta Sans (UI/body, Turkish glyphs OK) + Fraunces (quotes/mission). Google Fonts, system fallback.
- Logo hotlinked: `https://birizdernegi.org/wp-content/uploads/2019/05/Biriz_Logo-2019yeni.png` (download into the theme before launch).
- Radius 14/22px, soft shadows, max container 1180px. No images besides logo — covers/avatars are CSS gradients + inline SVG icons (Feather-style).

Accessibility: skip link, semantic landmarks, `aria-current`, `aria-pressed` on filter buttons, `aria-live` filter count + form success,
visible focus ring (yellow), reduced-motion respected, form errors per field, all icons `aria-hidden`.

## 5. Migration notes (→ WordPress)
- Recommended: block theme + `theme.json` with the tokens above; rebuild sections as block patterns. Avoid page builders.
- CPT `proje` with fields: `yil`, `tema` (taxonomy, 6 terms = work areas), `durum` (devam/tamam), `yer`, `ortak`, `link`.
  Projeler page = query loop + small JS or taxonomy filter. Work-area pages can query by the same taxonomy.
- Haberler = standard posts with categories (Proje, Eğitim, Ödül, Kurumsal, Duyuru…).
- People: CPT `kisi` with taxonomy `kurul` (Yönetim Kurulu / Yürütme Kurulu / Proje Ekibi / Gönüllü).
- Forms: CF7/Fluent Forms with KVKK checkbox, sending to bilgi@birizdernegi.org; add spam protection.
- 301 redirects from legacy slugs: `/kurucular-ve-yonetim-kurulu/`→`/yonetim/`, `/ekibimiz-2/`→`/ekibimiz/`,
  `/calisma-alanlari-yontemleri-hedef-kitlesi/`→`/projeler/`, `/projelerimiz/`→`/projeler/`, `/kurumsal-belgeler/`→`/kaynaklar/`,
  `/mali-tablolar/`→`/kaynaklar/`, `/bagisci-haklari-beyannamesi/` keep or →`/kaynaklar/#bagisci-haklari`.
- Keep existing `/wp-content/uploads/...` PDF URLs alive (donors and auditors link to them).
- Self-host the logo and fonts (KVKK/GDPR: Google Fonts hotlinking transfers IPs).

## 6. Files / how to run
- Build: `cd biriz-demo && python3 _kaynak/build.py`
- Serve: `python3 -m http.server 8787 --bind 0.0.0.0` → http://localhost:8787
- Zip of the whole folder: `/workspace/biriz-demo.zip`
